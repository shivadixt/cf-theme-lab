Privacy Policy

CF Theme Lab — Bauhaus & Papercut

Last updated: November 2, 2026

CF Theme Lab changes the appearance of Codeforces pages and is designed to work locally in your browser.

Information the extension handles

  • Theme preferences: The extension stores two settings, enabled and theme, using Chrome's chrome.storage.sync API. Chrome may synchronize these preferences across your signed-in browsers when sync is enabled.
  • Active tab URL: When the popup opens, it reads the active tab URL only to show whether the current tab is a Codeforces page. This value is not saved, logged, or transmitted.
  • Codeforces page content: The content script applies the theme to the page being viewed. It does not collect, copy, or transmit page content, submissions, source code, handles, comments, or browsing history.

Data sharing and sale

The extension does not sell or share user data with the developer or third parties. It does not make independent network requests to analytics, advertising, or developer servers, and it does not include tracking pixels. Chrome handles synchronization of the two saved preferences through its built-in Sync service when enabled.

Remote code and external services

The extension does not load remote scripts, remote stylesheets, or other executable code from external servers. Its styling and popup assets are packaged inside the extension.

Permissions

  • Storage: Saves the enabled and theme preferences through Chrome Sync storage.
  • Codeforces host access: Allows the content script and stylesheet to run on Codeforces domains so the page can be themed.

Retention and deletion

The extension retains only the two theme preferences in Chrome Sync storage. You can remove the extension or clear its stored extension data through Chrome to remove these preferences. Chrome Sync retention and deletion are also subject to your Google account and browser sync settings.

Changes and contact

If data practices change, this policy will be updated before or alongside the relevant release. For privacy questions or support, use the contact method listed on the CF Theme Lab GitHub repository or Chrome Web Store listing.
